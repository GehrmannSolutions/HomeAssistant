    Backups

    Backups of Home Assistant (configuration and database) through Home Assistant's own backup feature. Creating needs "Change configuration", deleting and restoring need "Allow delete". Before every restore the MCP makes a safety backup of the current state; Home Assistant restarts afterwards. Add-ons and folders are never reset.

    Changes

    Before every configuration change through the MCP (automations, scripts, scenes, dashboards, helpers, areas, floors, devices, entities, integration settings, files) the previous state is saved locally and kept for 30 days. "Undo" writes it back; the undo itself appears in the list and can be taken back too. Needs "Change configuration"; if something is removed, also "Allow delete". Not recorded: switching devices, removing integrations, options dialogs and backups.
