Verbinde den MCP mit deiner Home-Assistant-Instanz. Den Token erstellst du in Home Assistant unter Profil → Sicherheit → Langlebige Zugriffstoken.

Wähle das lokale Modell, mit dem du chatten möchtest. Es läuft über Ollama auf diesem Rechner.

Standard ist nur lesen. Schreibrechte kannst du jederzeit in den Einstellungen ändern; im Chat musst du zusätzlich jede einzelne Aktion bestätigen.

    Backups

    Sicherungen von Home Assistant (Konfiguration und Datenbank) über die Backup-Funktion von Home Assistant selbst. Erstellen braucht „Konfiguration ändern“, Löschen „Löschen erlauben“. Wiederherstellen geht bewusst nur in Home Assistant (Einstellungen → System → Backups), weil es die laufende Konfiguration ersetzt und neu startet.

    NameDatumGrößeSpeicherort

    Noch keine Backups.

    Änderungen

    Vor jeder Konfigurationsänderung über den MCP (Automationen, Skripte, Szenen, Dashboards, Helfer, Bereiche, Etagen, Geräte, Entitäten, Integrations-Einstellungen) wird der vorherige Stand lokal gespeichert und 30 Tage aufbewahrt. „Rückgängig“ schreibt ihn zurück; das Rückgängigmachen erscheint selbst wieder in der Liste und lässt sich ebenso zurücknehmen. Braucht „Konfiguration ändern“; wenn dabei etwas entfernt wird, zusätzlich „Löschen erlauben“. Nicht erfasst: Schalten von Geräten, Integrationen hinzufügen/entfernen, Options-Dialoge und Backups.

    ZeitWasZielVorherStatus

    Noch keine Änderungen erfasst.

    Dateien

    Pläne und Skripte, die das Modell im Chat erzeugt hat. Sie liegen nur auf diesem Rechner und werden nie automatisch ausgeführt. Lesen, herunterladen oder löschen.
